# Gestor de Reclamos para Transportistas – Yobel SCM

Este proyecto es una *aplicación web interna* que permite registrar, visualizar y dar respuesta automática a reclamos enviados por transportistas. Está desarrollado usando **Google Forms**, **Google Sheets**, **AppSheet** y **Google Apps Script**, con el objetivo de centralizar la atención y mejorar la trazabilidad de incidencias logísticas.


# Funcionalidades

- Registro de reclamos mediante formulario en línea (Google Forms)
- Generación automática de número de ticket
- Visualización de reclamos en AppSheet para el equipo de soporte
- Respuestas automatizadas por correo desde la app
- Integración con bases de datos estructuradas en Google Sheets


# Tecnologías utilizadas

- Google Sheets
- Google Forms
- Google Apps Script
- AppSheet
- Automatización por scripts
- Correo electrónico (Gmail API)
